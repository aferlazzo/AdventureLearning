# AdventureLearning

AdventureLearning is the shared, subject-neutral foundation for Tony Ferlazzo's interactive Learning Adventures.

DCG is the proving ground. General lessons that survive DCG testing are promoted here so projects such as HOA (Home Owner Adventures) inherit the same safety and usability standards without copying driving-specific content.

## Shared quality contract

The contract currently protects these rules:

- every choice points to a real outcome;
- every non-final outcome offers a way forward;
- Restart and Share controls exist;
- duplicate IDs are rejected;
- unresolved merge markers are rejected;
- adventure pages include mobile viewport support;
- JavaScript files must parse successfully.

Projects consume this repository from GitHub Actions. Updates to the contract are therefore picked up automatically by their scheduled and change-triggered quality gates.
